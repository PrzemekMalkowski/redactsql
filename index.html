Table names become table1, columns become <type>_column<n> (e.g. varchar_column1), indexes index1. Foreign keys are rewritten to point at the renamed tables and columns, so relationships survive. Comments, string defaults, and ENUM values are stripped; data rows (INSERT, COPY) and anything that can't be safely transformed are dropped.
Same engine on the command line: cat dump.sql | redactsql -o clean.sql -remove-fk v0.1.0
